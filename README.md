This project uses the Vehicle Dataset from CarDekho to explore the factors that influence used-car prices and build regression models capable of predicting a vehicle's selling price.

The project covers the complete machine learning workflow:
Data exploration and analysis
Data cleaning
Feature engineering
Categorical encoding
Feature scaling
Outlier analysis
Multicollinearity analysis using VIF
Regression model comparison
Cross-validation
Ensemble learning
Residual analysis
Price prediction for a new vehicle
